URL Upload Guide

Zoom Recordings

How to get the download link:

  1. Go to Zoom web portal → Recordings
  2. Find your recording and click "Share"
  3. Copy the "Download" link (not the viewing link)
  4. Paste the download URL into MinuteMate

Google Drive

How to get the download link:

  1. Right-click your file in Google Drive
  2. Select "Get link" and set to "Anyone with the link"
  3. Copy the sharing link
  4. Convert to download format: Replace "view" with "download" in the URL

Dropbox

How to get the download link:

  1. Right-click your file in Dropbox
  2. Select "Copy link"
  3. Change "?dl=0" to "?dl=1" at the end of the URL
  4. Paste the modified URL into MinuteMate

Not Supported

These platforms require downloading first:

  • YouTube videos
  • Vimeo videos
  • Facebook videos
  • Instagram videos
  • TikTok videos

Tip: Download these files first, then use the "Upload File" option.
